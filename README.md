# 分包比选工作台

把申请报告、商名录和各家资源投入计划里的队伍负责人、专业项目经理，汇总到会审表里。

页面分成四块：项目首页、资料导入、名单核对、表格导出。宽屏用侧栏，手机用底部导航。

默认打开双峰北 220kV 地基基础示例。也可以在资料导入里放入别的站点的申请报告、外包商名录和各家投入计划。文本型 PDF 直接抽文字；扫描件在本机用中文识别读第一页，可取消。读不到的姓名留空。法定代表人只作为候选，不会自动写入队伍负责人。情况说明不进入会审表。是否同意保持未勾选。源 PDF 不上传、不放进仓库。

## 打开软件

- 网址：[https://2010153875qq.github.io/fenbao-bixuan/](https://2010153875qq.github.io/fenbao-bixuan/)
- 手机 / 平板：用 Safari 或 Chrome 打开上面的网址，再「添加到主屏幕」，以后就像普通软件一样从桌面进入。安装提示可以关闭，不会挡住内容。
- 本页只展示会审名单，不含身份证号、社保证明或手机号。
- 源 PDF 未上传。资料导入只在本机列出所选文件名，不会上传，也不会识别正文。
